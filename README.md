# simplefuturegames.github.io

Website for Simple Future AB's games, served by GitHub Pages at
https://simplefuturegames.github.io. This is the developer website listed in Google Play.

| File | URL | Why |
|------|-----|-----|
| `app-ads.txt` | https://simplefuturegames.github.io/app-ads.txt | AdMob checks it at the root of the developer website before serving ads at full rate. Holds the AdMob publisher ID. |
| `quiverpop-privacy/index.html` | https://simplefuturegames.github.io/quiverpop-privacy/ | Quiver Pop's privacy policy. Linked from the Play listing, the Data safety form and the game's About screen. |
| `index.html` | https://simplefuturegames.github.io/ | Start page. |

`.nojekyll` makes Pages serve the files as they are. Changes go live a minute or so after a push
to `main`.

Update the privacy policy (and its date) whenever a game starts handling data differently, for
example when analytics are added.
